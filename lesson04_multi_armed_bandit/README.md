# 第四节课：10臂强盗问题 - ε-贪婪策略实验

这是强化学习课程第四节课的实验内容，专注于多臂强盗问题中的ε-贪婪策略。

## 🎯 实验目标

理解强化学习中**探索与利用**的权衡，对比三种不同的ε-贪婪策略：

- **ε = 0**（纯贪婪）：完全利用，不进行探索
- **ε = 0.01**（少量探索）：99%利用，1%探索  
- **ε = 0.1**（较多探索）：90%利用，10%探索

## 📊 核心概念

### 多臂强盗问题
- 10个动作臂，每个臂有未知的奖励期望值q*(a)
- 目标：在有限时间内找到最优动作并最大化累积奖励

### ε-贪婪策略
- **探索**：以ε概率随机选择动作，发现可能更好的选择
- **利用**：以(1-ε)概率选择当前估计最优的动作

## 📈 实验结果分析

### ε = 0（纯贪婪策略）
- **现象**：最优动作选择率低且稳定
- **原因**：初期随机选择一个动作后就"锁定"，无法探索更好的选择
- **问题**：过早收敛到次优解

### ε = 0.01（少量探索）
- **现象**：最优动作选择率缓慢但稳定提升
- **原因**：1%的探索时间逐渐发现真正的最优动作
- **特点**：平衡性较好，但收敛较慢

### ε = 0.1（较多探索）
- **现象**：最优动作选择率快速提升，趋向于90%
- **原因**：10%的探索充分，能较快找到真正最优动作
- **注意**：理论上限是90%（因为还有10%时间在探索）

## 🔬 关键学习点

1. **探索的必要性**：纯贪婪策略容易陷入局部最优
2. **样本平均法**：使用增量更新估计动作价值
3. **统计显著性**：多次独立运行的重要性
4. **权衡策略**：探索率的选择直接影响算法性能
